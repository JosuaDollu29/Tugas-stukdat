# 2EZ4U Food Delivery App
Tugas Final Struktur Data dan Analisa Algoritma (M1, M2, M3)

## 📌 Deskripsi Proyek
Proyek ini adalah simulasi aplikasi layanan pesan antar makanan (2EZ4U) berbasis Python dan Tkinter. Aplikasi ini memproses 200.000 data pesanan menggunakan implementasi murni tanpa fungsi bawaan (built-in) Python seperti `.sort()` atau modul tambahan lainnya.

## 🚀 Cara Menjalankan Aplikasi
1. Pastikan sudah tepat berada di direktori utama proyek.
2. Buka terminal dan jalankan perintah berikut:
   ```bash
   python frontend/app.py
